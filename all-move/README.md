## 当前核心结论

> 游戏不能靠外围系统救核心玩法。《羊了个羊》最值得借鉴的是：规则极简单、前段建立信心、中后段制造强压力、失败接近成功、有限救场、每日共同挑战和可比较结果。

> 本作真正需要建立自己的Signature Mechanic：**一次输入触发多个不同响应；并且玩家可以在局中改变这些角色以后如何响应。**

> 为弥补抽象Puzzle缺少“节目效果”的问题，首章进一步提出：**每种性格对应固定音色，一次全局响应同时构成视觉连锁和短音乐反馈。玩家每滑一步，都像拨动一只会发声的小机械盒。**

## 当前首章验证节点

- L1《你去哪，我去哪》：无需文字理解全员响应；
- L3《三个脾气》：验证“一滑多响”本身是否爽；
- L5《你变了》：首次发现可以修改NPC以后如何响应；
- L6《故意撞一下》：从躲碰撞升级为主动用碰撞交换性格；
- L10《他们终于都听懂了》：一个普通手势触发全员不同动作并同时落位。

## 下一步讨论顺序

- Step 1：只实现 L1 / L3 / L5 / L6 / L10 五个垂直切片，不先做50关；
- Step 2：用Solver校验L6、L8、L10的最短解和旁路解，微调棋盘；
- Step 3：确定第一版人物视觉语言与5种固定音色；
- Step 4：找真实玩家盲测，禁止口头解释规则；
- Step 5：根据盲测决定是扩大关卡，还是重做核心反馈。
