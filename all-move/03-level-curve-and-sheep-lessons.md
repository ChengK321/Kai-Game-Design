# 关卡节奏与《羊了个羊》可借鉴原则

## 1. 借鉴的是“情绪曲线”，不是表面形式

《羊了个羊》值得借鉴的不是三消皮肤，而是几件结构性设计：

1. 规则极易理解，首局几乎不用教学；
2. 前段给予玩家“我会玩”的信心；
3. 中后段迅速提高局面压力，形成明显难度悬崖；
4. 大量失败发生在玩家已经投入较多时间以后，产生Near Miss和沉没投入；
5. 有有限的撤销/移出/洗牌等救场能力；
6. 每日共同挑战、好友/地区比较，把单机结果变成社会话题；
7. 每天局面不同，但底层规则不变。

本项目只能吸收这些结构，不应复制“极高第二关难度”本身。

## 2. 《我一动，他们全动》的关卡曲线

建议一局不是100个小关，而是一个主题章节内8–12个短关，单关10–60秒。

### 阶段A：建立控制感（1–3关）

目标：让玩家快速理解“一动全动”。

- L1：玩家 + 跟屁虫；
- L2：加入杠精；
- L3：加入路痴；

成功率应很高，不追求难度。

### 阶段B：开始利用冲突（4–6关）

目标：从“避开别人”变成“利用别人”。

- L4：碰撞换位；
- L5：角色踩机关后行为改变；
- L6：玩家必须故意制造碰撞才能解题。

L5是首个Signature Moment：玩家意识到自己可以改变角色后续行为。

### 阶段C：产生局面压力（7–9关）

目标：让简单规则组合成复杂局面。

- L7：慢半拍，引入时间维度；
- L8：两个角色不能相遇；
- L9：5个角色+2种机关，但仍只允许3种主要行为类型。

### 阶段D：接近成功的高压局（10关）

目标：制造一次“一步全成”的强收束。

- 需要4个实体在同一次输入后分别完成不同目标；
- 玩家通常在倒数1–2步才发现早期布局错误；
- 允许一次撤销或重置局部状态，作为未来激励视频接口。

## 3. 难度不靠新增规则堆砌

每10关最多新增1–2个核心机制。后续难度来自：

- 角色初始位置；
- 障碍与目标排列；
- 有限步数；
- 同一机制之间的交叉影响；
- 角色规则在局中变化；
- 最优解与普通通关解之间的差距。

## 4. “羊式难度悬崖”如何适度使用

不建议做“前面极简单、突然近乎无解”。更适合的是：

- 前70%让大多数玩家能推进；
- 最后20–30%明显提高规划要求；
- 玩家多数失败在已经看见解法、但少一步或一步走错的位置；
- 高难关必须可稳定求解，避免依赖随机卡死。

## 5. 救场机制

首版最多保留两个：

### 撤销
撤销最后1–3步。最符合Puzzle玩家心理，也是最自然的激励广告入口。

### 暂停预演
允许玩家预览下一步所有角色将移动到哪里，但不真正执行。可作为免费限次或奖励道具。

不建议同时加入洗牌、额外步数、复活、强提示等过多道具。

## 6. Daily Challenge

正式版本可加入每日同一高难局：

- 所有人同一个Seed；
- 只比较通关与步数，不影响主线；
- 好友榜显示“已过 / 步数 / 是否完美”；
- 分享进入同一局，而不是强制拉人助力。

这才是适合本项目的“羊式社交放大器”。
