# Route B 验证协议 V2.1 — 麻将自主整理 / Sandtrix 差异化

日期：2026-10-09
状态：实验设计（HYPOTHESIS）；尚未实现 HTML 原型或邀请真人，也没有测试结果。
依赖：GLOBAL_DISTILLATION_V2.0_12.md；GAMES.tsv 的 Wilmot's Warehouse 与 Sandtrix 条目。
目的：先验证一个玩家真正自发喜爱的行动，再决定是否做游戏；避免变成普通“麻将三消 / 找相同”或另一款 Sandtrix。

## A. Mahjong Warehouse / 麻将小仓库：真正检验「我建立秩序 → 后续受益」

### 已核实的先例
- Wilmot's Warehouse：自行组织货物，再按服务口订单取回。Steam 官方：https://store.steampowered.com/app/839870/
- Mahjong Stack: Tile Sort：麻将堆叠整理，Google Play：https://play.google.com/store/apps/details?id=com.sg.mahjong.stack.tile.sort.puzzle
- Mahjong Shelf: Sort Puzzle：架上分类/同类清除，Google Play：https://play.google.com/store/apps/details?id=com.kite.mahjongshelf
- Mix Mahjong Sort：已出现“麻将有限缓冲/分类”的不同设计，Google Play：https://play.google.com/store/apps/details?id=com.jinlinetwork.mix.mjsort

### 新的用户建议与判断
把方块符号替换成麻将牌面，可用数/花色天然视觉语义降低资产成本，便于识别；但**可能将自由整理退化为显而易见的按花色-大小排序**，尤其自动排序就能代替人类选择；新手可能不认麻将。是否真正保留 Wilmot 的自建分类乐趣，属于未知。
用“麻将”只做图形载体，不采用碰/杠/胡/配对消除、分数连击、题材人物或额外道具。

### 极小可测试局面
- 24 张：万、筒、条三种花色 × 一到四四种数字 × 每种两张。屏幕上固定 4×6/6×4 布局，卡面清楚。全部可见，先不叠放/遮挡/限时间/加道具。
- 整理阶段：测试者可自由拖动两张交换位置、决定自己的摆法，最多观察约 45–60 秒（不是必须等待或强迫排序）。
- 取牌阶段：随机给出目标，例如“三筒”“二条”，通过轻触取到对应一张；连续约 10 轮。取到的牌在实验中回到原格，以固定库存消除“越取越少”的干扰。这是测试便利，不预先定为成品规则。
- 不教分类方法，只说明目标操作。观察是否主动整理、采用了何种布局、多久能记住、是否说得清“我按自己的办法摆的”。

### 必须有的三条件比较（不然无法得出自由整理的价值）
1. RANDOM：相同牌组随机布局；不能预整理，直接取牌。
2. SELF：玩家自由安排布局；允许自主选择分类法和位置。
3. AUTO：系统按花色与数字排列；直接取牌（尤其重要，它是更强的替代方案）。
所有条件同类目标、相近难度/频次；顺序平衡或用等价牌组与不同伪随机种子，防止先玩某一条件带来的学习效应。

### 记录（不要把任务成绩当成乐趣）
- 首次 10 秒是否自然理解整理/取牌；
- 整理耗时、每次定位耗时、错选次数、合计耗时；是否需要多少次目标请求才收回提前整理的时间；
- 玩家有无**主动**重排和自己的策略（不能诱导），愿不愿意再来五轮；
- 整理本身是否愉悦，还是只觉得“准备工作/记忆考试”；玩家知不知道麻将在说什么，避免误把牌面理解成本当机制成本；
- 自动排序基线如果在总耗时和体验上更优，则“自由整理”没有得到价值证据，不能拿比 RANDOM 快就证明玩法成立。

### Gate / Kill
G0：6–8 人探索样本，包含至少 2 个不熟麻将者；用于观察明显 UX 风险，不推断留存或统计显著性。
G1：玩家自发整理，在随后取牌时表现出实际可理解的正反馈；能说明自主组织的理由。
G2：自由整理的乐趣/可学决策明显不是自动排列或随机找牌能够替代；如果 AUTO 快且更舒服、无人坚持 SELF，则取消「自由整理→取回」的开发路线。
G3：五轮后有自发继续理由；若需要库存遮挡、倒计时、道具或复杂仓库模拟才能成立，应先停而非堆机制。
强反例：麻将花色及数序内置“正确整理方案”，可能没有原作商品多种解释带来的个体分类乐趣。纯麻将符号较抽象图形可读，但较语义丰富商品也可能降低感性奖励。
下一证据：只做静态纸面/简单点击交换测试，再决定 HTML 交互原型（约 0.5–1.5 天工作量估计，不是承诺）。

## B. Sandtrix：先确认独立决策，不把落沙的外观变化当新机制

### 官方可证的 S0 基线（FACT）
- 原版由 msky-dev 开发，图形块落下后变为沙粒，通过同色连续区域从左到右连通来清除。免费基础版已有多种模式，Sandtrix+ 又有更多颜色、玩法模式和视觉效果。
- https://msky-dev.itch.io/sandtrix
- https://www.crazygames.com/game/sandtrix
- https://store.steampowered.com/app/2546310/Sandtrix/
这意味着“积木变沙 + 横向同色消除”“减少美术”“再加颜色模式”均不是本研究可主张的新核心。

### 外部相邻基因（不是一款游戏的新发明）
- SandTris™（UniRise）也公开采用下落方块 + 沙物理 + 行消除：https://apps.apple.com/us/app/sandtris/id6749531088
- Sand Balls：引导沙中球体到目标的路线玩法，见 SayGames：https://say.games/games/
- 旋转/改变重力：Gravity Grid: Color Drop（App Store）：https://apps.apple.com/us/app/gravity-grid-color-drop/id6794268530
- Grainfall 已具备倾斜重力的沙粒模拟：https://jakehaas.com/apps/grainfall/
注意 Sandtrix、别名 Sandtris/Setris 与其他开发商的 SandTris™ 是不同的条目，不要只按名称合并。

### 先做的是差异检查，不是新产品设计
写出原作的 4 个因果核：
玩家操作（控制块的落点/旋转）→ 状态变化（落地后分散成颗粒）→ 目标（左至右同色相连）→ 长期压力（棋盘堆积）。

先做三个“实验对照/消融”，不是三款新游戏：
S0：试玩原版，记录哪个步骤真正愉快、哪些局面可预判；
S1：纸面/轻量逻辑模型去掉颗粒，只保留颜色连接，看局面决策是否依然存在（验证颗粒是否必要）；
S2：粗颗粒/简化散落，不复制完整像素模拟，保留 S0 的清除条件，看是否以更小成本保留真实体感。
若 S1≈S0，沙粒可能主要是反馈而非策略来源；若 S2 相对 S0 明显变差，则当前乐趣对物理细节高度依赖、Solo Fit 下调。
不能以 S2 好玩作为创新证明：它仍是 Sandtrix 的简化实现。

### 独立候选如果出现，才执行差异矩阵
- **Operation**：从玩家可用操作的效果出发，与“选落点/旋转后等沙流”是否不同？
- **Constraint**：是否改了玩家应当预判/权衡的对象，而不是只改颜色/得分/动画？
- **Future State**：每一步是否产生原作未提供的下一步决策空间？
- **Competitive prior art**：玩法是否已经是沙球挖路、转重力、经典沙消除中的常见模式？
- **Solo Fit**：能否用 2D 单指、粗颗粒或图形替代方案在 1–3 天验证，后续是否避免海量题库与物理 QA？
没有通过 Operation+Constraint+Future State 的清晰变化，立即停在 REFERENCE，不进入原型。

### Next Evidence
1. 先亲玩官方 Sandtrix HTML5 约 10–15 分钟，对照几局记录成功与失误为何产生，不用拆包、不复制具体源码/关卡。
2. 无需编游戏，先填一张 S0/S1/S2 的“相同局面，各自什么操作会更好？”对照表；如无法说出差别，说明更像换表现。
3. 必须找到一条玩家行为明显不同、且未被同类产品充分覆盖的规则假设，才准许单屏低分辨率模拟/少量真人验证。
4. 如果只证明沙落下很爽但无独立玩法，则终止商业提纯候选、保留为“形变反馈”基因素材。
状态：REFERENCE / NOVELTY_GATE_OPEN（不是 PRE-PROTOTYPE）。

## Decision Log
Decision：麻将作为识别清楚、低资产的载体做三条件小样本对照；不当作已形成新玩法。Sandtrix 本轮保持高门槛差异审查，优先做基线规则/既有玩法边界，不写原型。
Evidence：上述原作/官方商店描述属于 FACT，体验迁移与创业价值仍为 HYPOTHESIS。
Counter：麻将自动排序消灭自组织价值；Sandtrix 已经高度提纯且有复制/类同作品，新设计易只是换皮。
Unknown：真实愉悦、系统自排序的替代、颗粒运动对决策的贡献、同类拥挤、产品分发。
Kill：测试者只感到“按要求找牌”；没有自发整理；或 Sandtrix 改法仅改变外观和积分而非行动-约束-状态的因果。
