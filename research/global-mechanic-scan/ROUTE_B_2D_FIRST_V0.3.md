# Route B V0.3｜2D-first，3D-by-exception，缩小扫描批次

## Decision
把 V0.2 的「源游戏全类型开放」收紧为 **2D 优先、低成本平面化优先、3D 例外准入**。
不是因为 3D 原作不优秀，而是因为它经常需要依赖大空间导航、多视角反馈、物理精度、复杂资产与系统，提纯后核心乐趣可能不复存在。
但不以“原作是 3D”为唯一淘汰理由：只要核心动作低成本映射为二维且体验因果依然成立，允许以小比例例外候选纳入。

## Discovery budget
- 每轮深入样本原则上 12 款（替代上一版拟议的 30 款）；
- 约 10 款优先来自原生 2D、2.5D 或无需复杂仿真的平面化作品；
- 最多 2 款为 3D 例外，须先写出二维版本的一句话规则和核心操作，不通过则不占详评篇幅；
- 保留不同体验家族的来源，不让“2D”变成只看同一类网格解谜；
- 每轮结论只保留 2–3 个待验证机制候选，其余记录来源和淘汰原因即可；
- 预算是探索管理而非统计抽样，不证明全面覆盖或排名。

## 先粗筛，再研究：三个快速 Gate
### Gate A：核心快乐可搬运
能在 1–2 句话说清原作中玩家会主动反复做的**动作—立即反馈—下一步变化**；并说明剔除题材、角色、成长系统后还保留什么乐趣。如果核心快感依赖真实 3D 空间、海量内容或多人合作，淘汰该提纯候选（原作可保留为参考）。

### Gate B：目标表达原生直观
二维单屏/少量切屏，尽量单指操作；简单线条、色块、基本动画和少量声音能自然表达动作、状态和约束。不能靠编号、教程、复杂 UI 代偿不直观的规则。2.5D 若只用于表现、无需难的三维物理与美术资产，可与 2D 同一优先池。

### Gate C：一人实验室试错成本
AI 辅助下优先 1–3 天做出验证核心快乐的 Playable Probe；若超过一周才能验证、需要重美术/精细 3D 操控/大量手工关卡/复杂平衡/后端多人系统则先淘汰。评估**工程成本 + 手感/反馈成本 + 内容供给成本**，而非仅代码量。
原型可行≠长期产品可行，5 局之后的策略或技巧增长要在后续人测单独验证。

## 跨类别优先搜索
- 2D：放置、消除、滑动、牵引、遮挡、整理、反弹、局部群体反馈、实时技能操作；
- 2.5D：有表现层纵深，但核心机制可用二维拓扑/平面碰撞表达；
- 3D 例外：仅在显然能无损或低损提取核心动作时加入；例如时序控制可降到二维，但曾讨论过的“我动敌动”不是新发现，需严查同类和以前试错证据；
- 暂不追逐：3D 第一人称精准操作、复杂模拟驾驶、多角色动画重作、多人生存和大规模装备成长等。

## 为什么不仅按维度筛选
- 一款二维作品可能依赖 100+ 手工关卡、长期数值平衡，实际上不适合个人开发；
- 三维作品的某个状态约束可能一眼就能二维化，这时把原作排除会错失机制；
- 因此真正的准入对象是**提纯后的一人可验证机制**，不是原作的画质或类型标签。

## Evidence / Counter / Unknown / Kill
- FACT: 已有 50 款机制研究以及 Ring Shift、Endless Peel、交点亮灯等探索；交点亮灯展示了读图成本会吞噬规则简单性的实测风险。
- INFERENCE: 缩小批次并提前筛除高迁移成本，可减少研究注意力浪费；2D-first 可能提升低成本原型转化率。
- COUNTER: 过早限制为 2D 可能使启发来源同质化；为了防止盲点保留小比例 3D 例外。
- UNKNOWN: 哪个机制家族实际更有复玩、留存和可获取用户；目前没有相关样本对照实验。
- KILL: 需要增加多个规则、重资产或数周开发才看得见乐趣；简化后核心感受丢失；只能复制现有成熟竞品却没有可感体验差异。
- NEXT EVIDENCE: 执行一轮 12 样本轻量扫描，每项只记 Source → Core Pleasure → Minimal Rule → Cheapest 2D Carrier → Solo Gate → Counter/Kill → State。仅对 2–3 项做深入讨论/原型资格复核。
