# One-Rule Emergent Puzzle｜第二轮研究 Decision Log V0.3
2026-10-09｜`research/gamelab-50`｜从50组截图抽象规则；仅依据算法验证筛选，不对任何候选承诺上线。当前游戏设计工作与其他正式项目分离。

## 真实目标
不是寻找「长得像数独/2048」的游戏，而是找高规则密度的可重复状态机：**一次动作能带来直接收益；同时积累未来约束；玩家看得见成长目标；差的选择与好的选择能产生可学习的差别**。这四项要分别验证，不能因为前三项成立就推导留存/爆款。

## 本轮新证据与实测
1. **Endless Peel / 双端剥离**：模拟器、6条规则单测、可交互 HTML 原型和真实浏览器 smoke test 已完成。220 seed、150回合上限：4色/每回合随机补4/容量10时，随机中位10回合，贪心33，空间压力57.5，简单前瞻71，知道补块的辅助代理≥150（封顶）。仅改变每回合补量3→5，就可从多数好策略到达150上限变成中位13回合，风险明显。
2. 180 seed 敏感性补充：4色/随机补4/容量8时，随机6、贪心15、前瞻24；5色/每排补1/容量9时，随机8、贪心23、前瞻31。不同设置是候选可玩区间，不是单变量 A/B。
3. 300 seed 前瞻决策采样：A(4色随机补4容量8) 9957次策略动作，有13.7%主动牺牲即时最高剥除量，≥4块连剥出现率58.0%；B(5色每排生1容量9) 11417次，主动牺牲率13.6%，≥4块比例53.3%。这些是算法所访问状态上的**条件频率**，不能当作玩家行为。
4. **Ring Shift / 对位滑环**：来源《移星掠形》行列移动 + 内外色对齐条件，4×4/4色/初始8颗/每次补2颗，180 seed/100上限，随机中位7回合，消最多37，简单前瞻98。说明规则中也可能存在策略差距。但动作选择达16种，是明显认知负担。
5. **翻盘流墨**：尚未建立确定、可解、易预测的同步流动规则；当前只留档，不启动原型。**吞噬滑棋**：成长不可逆且若新生小球长期都小于主球，生存模式可能迅速丧失压力；仍需明确对抗来源，暂不因「吞噬爽」升级。

## 反方（Evidence Red Team）
- 算法强于随机只能证明当前模拟决策有差异，不能证明玩家能掌握、感到有趣或形成留存。
- Endless Peel **没有 2048 的持续合成增长**，只有「释放空间/消除/产生新的块」，目前更像分配资源的长期防守，而不是明确朝 2048 目标成长。
- 已存在端点可移除的麻将类游戏、上升棋盘同色消除和行列滑动匹配等相邻机制；**原创性与市场成功均未证实**。
- 调参过拟合、隐藏补块的运气和 16 种输入动作都可能导致体验薄弱。不能以增加道具或包装解决核心循环问题。

## 当前决策 / Gate

## 真人测试预注册
- 完全无帮助首轮 10 秒；记录首次正确操作与是否准确复述因果。
- 同种子多局，比较人类操作和固定贪心策略的差别，记录最初5局玩法及自发重玩行为。
- 评估是否有「我想让下次剥离变得更大」或「我想提前布置一个高收益未来」的自发表述/操作迹象，而不先诱导答案。
- 玩过5局后若玩家仍只是选即时消最多、对继续玩无意愿，则降级/终止；不要通过技能、炸弹、升级系统挽救。
- 如果补块的公开预告增加认知负担而隐藏又造成不公平，应终止该 Endless 模式。
