# Color Lines V0.2 体验品质版交付记录（2026-10-10）

状态：可玩 HTML 已在当前对话作为文件交付；玩法规则维持 V0.1，尚未正式公开发行或通过 Product Gate。**HTML 源码仍为聊天附件，本报告不误称已存入仓库**。
文件名：Color_Lines_98_Kai_Experience_V0.2.html（独立离线 HTML）。

## 变更（不改规则）
- 原创 WebAudio 合成 SFX：选择、不可达、路径移动、落定、新球出生、五连消除逐级小旋律、结束。页面顶部提供独立音效快捷开关；背景氛围音乐在测试设置中可选，默认不自动播放。
- 清除亮起/收缩/渐隐、浮动加分、分数轻微弹跳，全部可通过系统 reduced-motion 关闭；动画尽量短，长局不拖沓。
- 自动保存每个完整回合的棋盘、分数、步数、预告点颜色/位置、seed 与 RNG 状态、over、一步撤销快照、音效/形状设置；可刷新继续。
- saveGame 在 busy 动画中不写入半步棋局；若此时关闭，恢复之前已经完整结算的局面。
- 延续 V0.1 的 9×9、七色、正交 BFS 可达路径、横竖斜五连消除、未消除补三球、预告重定位、满盘结束、每球两分、固定种子与撤销。

## 验证范围
- node --check：脚本语法通过；
- Chromium 通过页面内容注入执行（环境阻断 file:// 与本地 HTTP 导航，因此通过 about:blank set_content + 临时 localStorage stub 做测试，**不能等同于真实 Android 的 file:// 环境**）。
- 手机 390×844、电脑 1280×900 界面显示；无页面脚本异常。
- 五连得分10分、不同 seed 确定重开、路径完全受阻、预告位置被移动球占用后重定位、一步撤销并跨新页面保留、偏好开关与不自动播放背景音乐，都通过模拟浏览器测试。
- 近满盘结算 game over 并恢复；动画中尝试存档仍保留此前完整回合，避免半步快照。
- **尚未真人验收**音色、真实移动设备浏览器背景音、长局重开习惯、与其他现代 Color Lines 的体验比较。
- 因无法自动听觉评估，未宣称原创音效比原版更好听。

## V0.2 人测最小反馈
1. 是否在第一回合就听到移动/落定的声音，消除声是否舒服、是否单调？
2. 开启音乐十分钟后会不会干扰思考？音效与音乐能否分别关闭？
3. 退出重进是否确实恢复分数、预告及局面？在页面关闭后重开是否仍愿意继续？
4. V0.1 与 V0.2 相比，玩家最明显的正向变化是什么？有没有多余的动画时长？
5. 如果 V0.2 同样好玩但现代竞品提供的体验更完整，则仍只保留为研究对照，不自动立项。

## Decision Log
Decision: 将 V0.2 提交用户进行真实体验；后续不是立即开发 V0.3 新规则，而是先获得音画与重复游玩证据。
Evidence: 浏览器仿真验证的正确性，以及用户对 V0.1 操作顺畅的直接反馈。
Counter: 音效合成未经过真实设备听感验证；现代竞品已经有好动画/保存；此版既无原创规则也无独特商业定位。
Unknown: 音效舒适度、不同手机浏览器音频策略、长时间局面回访率、潜在产品差异化。
Kill: 若 V0.2 体验仍明显弱于现代同类，或核心缺乏额外玩家价值，不继续堆功能。
