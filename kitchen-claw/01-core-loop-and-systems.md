# 01｜核心循环与系统设计

## 1. 单局核心循环

玩家每次只做一个动作：**等待钩爪摆到合适角度 → 点一下 → 钩爪伸出 → 抓到碰撞到的第一件菜 → 菜被拉回 → 根据订单/备菜台处理 → 菜堆局面更新。**

循环必须在2–4秒内完成一次，保持强节奏。

## 2. 抓取规则

### 钩爪
- 自动左右摆动；
- 玩家点击后沿当前角度伸出；
- 碰到第一件可抓物立即锁定；
- 拉回速度快于黄金矿工，不做长时间拖拽；
- 碰撞判定宽松，强调“选什么”而不是“点得准不准”。

### 预判提示
钩爪方向上显示一条很淡的辅助线，当前预计命中的菜轻微描边。这样降低操作摩擦。

### 抓空
V0.01中不做严重惩罚，只损失1次动作节拍。后续营业模式可损失少量时间。

## 3. 遮挡系统

每个菜盘拥有：
- 占用形状；
- 层级Z；
- 支撑关系；
- 可抓区域；
- 是否被其他物体遮挡。

玩家只能抓到钩子路径上第一个可碰撞对象。

遮挡的乐趣来自：
- 目标明明看得到，但抓不到；
- 抓走上层菜后，下面目标暴露；
- 同一个目标可能有两条清障路线；
- 选择哪条路线取决于未来订单与备菜台。

## 4. 备菜台

V0.01建议3格。

规则：
- 抓回的菜如果正好是当前订单下一道，直接上菜；
- 如果不是当前所需，则进入备菜台；
- 备菜台中的菜如果之后成为当前所需，自动上菜；
- 相同菜V0.01不合并；
- 备菜台满时再抓非当前目标，失败/需要救场。

备菜台不是惩罚槽，而是“有限前置缓存”。

## 5. 订单系统

屏幕上始终显示：
- 当前订单：完整菜序列，正在等待的下一道高亮；
- 下一单：完整预览；
- 再下一单：可只显示菜品图标或半透明预览，视难度决定。

V0.01建议当前单 + 下一单完全可见，避免信息不足导致随机感。

订单长度：
- 前3关：1–2道；
- 中期：2–3道；
- 后期：3–4道。

## 6. 自动上菜与连锁

这是核心爽点。

例：
当前订单：`虾 → 米饭 → 牛排`
备菜台已有：`[米饭][牛排][蛋糕]`

玩家抓到虾后：
1. 虾直接上菜；
2. 系统检测备菜台第一格有米饭，自动飞出；
3. 再检测牛排，继续飞出；
4. 整桌完成，产生“叮—叮—叮—锵”音效和Combo反馈。

这使提前规划立刻获得可感知奖励。

## 7. 菜堆变化

V0.01不做完全随机真实物理，采用“半物理可预测规则”：
- 上层支撑被移除后，菜品向最近空位下滑；
- 圆盘可横向滑1格；
- 大盘优先占据2格；
- 不允许无预兆的大范围随机洗牌。

目的不是制造混乱，而是让一次抓取同时改变未来可达性。

## 8. 失败条件

首版关卡制失败主要有两种：
1. 备菜台满后又抓到非当前所需菜；
2. 达到关卡最大抓取次数仍未完成订单。

营业模式后续可加入：
- 总时间耗尽；
- 急单超时；
- 连续错抓导致顾客离开。

## 9. Combo与评分

评分维度建议：
- 通关；
- 总抓取次数；
- 连锁上菜次数；
- 备菜台峰值占用；
- 是否零撤销。

不要一开始堆金币、星级、装修等Meta。

## 10. V0.01暂不加入

- 切菜/煎炒烹饪；
- 多种钩爪；
- 角色移动；
- 餐厅装修；
- Roguelike升级；
- 菜品合成；
- 顾客特殊技能；
- 随机道具。

先验证“抓取清障 = 未来备菜”是否本身足够有趣。
