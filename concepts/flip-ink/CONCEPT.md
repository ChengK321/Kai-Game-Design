# 翻盘流墨（Flip Ink）｜Concept V0.1
日期：2026-10-09｜来源：Gamelab 50 组截图中的《燃烧的画》分层颜料、《管道迷阵》局部流向规则
状态：WATCH / HIGH-RISK HYPOTHESIS｜定位：独立视觉玩法探索，不与 Chain Shot 主线关联

## 一句话
一张错乱的像素画里堆着颜料；向一侧滑动画板，溢出的颜料按重力流动，逐渐拼出目标图案。

## 初版规则（需先做规则自洽证明）
1. 4×4 格，最多两种颜色，每格堆叠 0–2 层；不同颜色遵循同样流动规则。
2. 一次上下左右滑动改变重力方向，所有可移动的上层颜料沿重力方向进入相邻可容纳格；一次结算同步、不可冲突。
3. 底层固定留在原位；移动直到稳定；最终每格恰好一层且颜色组成可识别的简单图案即过关。
4. 初版图案为线段、十字、爱心等；不使用原作的加热操作，不添加门/管道/颜料技能。
5. 上述规则可能导致目标不可达或动作不明确：在进入 UI 开发前必须形式化同步结算与容量限制，并用逆向生成确保可解性。

## 快乐循环
每次调整方向 → 颜料大面积流动 → 画面由混乱趋近有序 → 最后一块归位形成图案。

## 最强反方
看起来像流体模拟，但如果玩家看不懂为什么这滴颜料移动，结果会显得随机；「完成图画」又需要固定关卡和资源内容，可能与数独/2048式无限可玩目标冲突。市面重力球/流体排序已成熟。

## 测试
- 先用纯文字/格子模拟器证明操作确定、路径冲突规则明确、存在充分可解的题面；这是 Gate 0。
- 仅制作 4×4×2 色、8 个种子题。验证首轮玩家能否预测下一次整体流动。
- 观察有没有「最后形成图案」的高潮，而不是只有持续试错。
- Kill：若需超过两条额外特殊规则才能保证可玩，或真人无法预测每次运动，停止；美术升级不得作为掩盖规则问题的补救。
